# Educational Summary Templates

This document provides ready-to-use structural templates for different educational summarization formats.

---

## 1. Cornell Notes Template

Use this format when the user requests Cornell note-taking style or wants a note format optimized for lecture review.

```markdown
# 📓 Cornell Notes: [Lecture / Topic Title]
**Subject / Course**: [Course Name] | **Date / Session**: [Session # or Date]

| Cues & Trigger Questions | Detailed Notes |
| :--- | :--- |
| **[Key Term 1]**<br>• What is it?<br>• When was it formulated? | • **Definition**: [Rigorous definition]<br>• Primary characteristic: [Detail]<br>• Mathematical/formal representation: [Formula] |
| **[Mechanism / Process]**<br>• How does step A lead to step B?<br>• What is the catalyst? | 1. **Trigger**: [Condition]<br>2. **Intermediate Phase**: [Reaction or transition]<br>3. **Terminal State**: [Outcome] |
| **[Contrast Question]**<br>• How does X differ from Y? | • **X**: Focuses on [Feature 1], bounded by [Constraint 1]<br>• **Y**: Focuses on [Feature 2], bounded by [Constraint 2] |
| **[Application Scenario]**<br>• Under what condition does this fail? | • Critical edge case: [Condition]<br>• Prevention technique: [Remedy] |

---

### 📝 Summary (The Synthesis)
> [Write a 2–3 sentence synthesis capturing the essence of the notes above. Answer: "What is the primary conclusion of this lecture, and how do the parts fit together?"]
```

## 2. High-Yield Revision Sheet (Cheat Sheet)

Use this format for pre-exam cramming, fast lookup, or condensed cheat sheets.

```markdown
# ⚡ High-Yield Revision Sheet: [Subject / Topic]

## 🎯 1-Minute Core Formula & Law Index
| Law / Equation / Concept | Formula / Rule | Meaning of Variables | Key Application |
| :--- | :--- | :--- | :--- |
| [Concept A] | `E = mc²` | $E$: Energy, $m$: Mass, $c$: Light speed | Mass-energy equivalence |
| [Concept B] | ... | ... | ... |

## 🔑 Essential Vocabulary & Distinctions
- **[Term 1]** vs. **[Term 2]**: [1-sentence critical contrast that exam questions test].
- **[Term 3]**: [Exact 1-line definition with trigger keywords bolded].

## 🚦 Rule of Thumb & Quick Heuristics
- *If [Condition A]*, always choose **[Strategy 1]**.
- *If [Condition B]*, avoid **[Trap 1]** because **[Reason]**.

## 💣 Top 3 Exam Traps
1. **Trap 1**: Conflating [X] with [Y]. Remember: [Mnemonic / memory anchor].
2. **Trap 2**: Forgetting units / constraints in [Calculation].
3. **Trap 3**: Assuming [Common wrong assumption].
```

## 3. Active Recall Flashcard Deck (Anki / Quizlet Compatible)

Use this format when the user requests flashcards or spaced repetition materials.

```markdown
# 🗂️ Flashcard Deck: [Topic Title]

### Card 1: Fundamental Concept
**Front**: What is the primary definition and significance of [Concept Name]?  
**Back**:  
- **Definition**: [Concise, accurate statement]  
- **Why it matters**: [Key utility]  
- **Memory Anchor**: [Analogy or mnemonic]

---

### Card 2: Mechanism / Process
**Front**: What are the 3 sequential steps in [Process Name]?  
**Back**:  
1. [Step 1]  
2. [Step 2]  
3. [Step 3]

---

### Card 3: Distinction Challenge
**Front**: Contrast [Concept A] with [Concept B] across scope, mechanism, and performance.  
**Back**:  
| Dimension | [Concept A] | [Concept B] |
| :--- | :--- | :--- |
| **Scope** | ... | ... |
| **Mechanism** | ... | ... |
| **Cost / Tradeoff** | ... | ... |

---

### Card 4: Cloze Deletion / Formula
**Front**: In the context of [Domain], [Variable] is inversely proportional to {{c1::[Variable 2]}} when {{c2::[Parameter]}} is held constant.  
**Back**: Revealed cloze and brief derivation note.
```
